## ✨ 핵심 기능

1. **☀️ 오늘의 영농 작업 루틴 체크리스트:** 매일 필수(A/B원액 잔량, 센서 확인), 주간 생육(곁순제거, 적엽), 정기 점검 관리.
2. **⛅ 실시간 기상청 농업기상 & 일사량 센터:** 기상청 고해상도 격자 API 연동, 시간대별 일사량(W/m²) 예보 곡선, 스마트팜 급액·환기 맞춤 처방전.
3. **🌱 농진청 7단계 연간 생육 로드맵:** 정식일자 기반 경과일(DAT) 자동 계산, 표준 온도/습도/EC/pH/배액률 가이드 제공.
4. **🌿 1,000평 베드 매트릭스 (1~24번 베드):** 베드별 작업 진행 상태 및 7일 이상 경과 시 지연 알림.
5. **🧪 양액·환경 및 수확량 일일 대시보드:** 공급/배액 EC·pH 자동 편차 계산, 배액률 산출, 특품/보통 5kg 상자 계량, 1클릭 기상청 날씨 자동 입력.
6. **📈 영농 통계 & 분석 그래프:** Chart.js 기반 일자별 EC/pH 추이, 배액률 변화, 수확량 분석.
7. **☁️ 수파베이스 서울 클라우드 DB 실시간 양방향 동기화:** 노트북과 스마트폰 어디서 입력하든 초고속 실시간 저장 (오프라인 캐싱 지원).
8. **💾 엑셀(CSV) 및 전체 백업(JSON):** 모든 영농 일지 스프레드시트 1초 출력.
