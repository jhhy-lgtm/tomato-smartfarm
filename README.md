## ✨ 핵심 기능

1. **🔒 농장주 전용 6자리 PIN 번호 잠금 보안:** 첫 접속 시 키패드 잠금 화면 제공, 빠른 인증 및 원터치 수동 잠금.
2. **🏛️ 서울시농수산식품공사 가락시장 실시간 도매 경매 시세:** 5대 도매법인(서울청과, 농협, 중앙, 동화, 한국) 낙찰가 연동 및 출하 상자수 기반 예상 순수익 정산 계산기.
3. **🐛 농진청 & 전국 농업기술원 시기별 병해충 예찰 & IPM 방제 도감 (12종):** DAT 경과일 및 기상 온습도 기반 동적 경보 배너, 4단계 시기별 필터, 초기 식별 요령 및 친환경/IPM 방제 레시피.
4. **☀️ 오늘의 영농 작업 루틴 체크리스트:** 매일 필수(A/B원액 잔량, 센서 확인), 주간 생육(곁순제거, 적엽), 정기 점검 관리.
5. **⛅ 실시간 기상청 농업기상 & 일사량 센터:** 기상청 고해상도 격자 API 연동, 시간대별 일사량(W/m²) 예보 곡선, 스마트팜 급액·환기 맞춤 처방전.
6. **🌱 농진청 7단계 연간 생육 로드맵:** 정식일자 기반 경과일(DAT) 자동 계산, 표준 온도/습도/EC/pH/배액률 가이드 제공.
7. **🌿 1,000평 베드 매트릭스 (1~24번 베드):** 베드별 작업 진행 상태, 구역별 빠른 선택, 일괄 완료 및 지연 알림.
8. **🧪 양액·환경 및 수확량 일일 대시보드:** 공급/배액 EC·pH 자동 편차 계산, 배액률 산출, 병해충 원클릭 빠른 태그 추가, 사진 첨부.
9. **📈 영농 통계 & 분석 그래프:** Chart.js 기반 일자별 EC/pH 추이, 배액률 변화, 수확량 분석.
10. **☁️ 수파베이스 서울 클라우드 DB 실시간 양방향 동기화:** 노트북과 스마트폰 어디서 입력하든 초고속 실시간 저장 (오프라인 캐싱 지원).
11. **💾 엑셀(CSV) 및 전체 백업(JSON):** 모든 영농 일지 한국형 엑셀(UTF-8 BOM) 1초 출력.
