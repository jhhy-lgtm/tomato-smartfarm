# 🍅 토마토팜 매니저 (TomatoFarm Manager)
> **1,000평 완숙토마토 연동온실 스마트팜을 위한 1인 농장주 전용 통합 관리 시스템**

---

## 🌟 주요 기능 소개

### 1. 📌 오늘의 루틴 체크리스트
- 완숙토마토 스마트팜에 필수적인 **일일 필수 루틴**, **주간 생육 관리**, **정기 설비 및 방제 루틴** 기본 탑재
- 원터치 체크 및 실시간 달성률(%) 프로그레스 바
- 나만의 맞춤형 루틴(작업명, 주기, 상세 가이드) 무제한 추가

### 2. 🌿 1,000평 연동온실 베드별 작업 매트릭스
- 온실 내 **1번 ~ 24번(설정에서 변경 가능)** 베드의 작업 현황을 한눈에 시각화
- 작업 종류별 전환: `✂️ 곁순제거&유인`, `🍃 적엽(하엽)`, `🎯 적과(착과조절)`, `🍅 완숙과 수확`, `💧 점적·배액 점검`
- **구역 빠른 선택(1~6번, 7~12번 등) 및 원터치 일괄 완료 처리**
- 마지막 작업일 추적 및 **7일 이상 미작업 베드 경고 표시 (⚠️ 지연 알림)**

### 3. 🧪 양액·환경 및 수확 일일 대시보드
- 공급 EC vs 배액 EC, 공급 pH vs 배액 pH 측정값 기록 및 편차 판정
- 급액량(L) & 배액량(L) 입력 시 **배액률(%) 자동 계산** (적정 범위: 20~30%)
- 완숙토마토 등급별(특품, 보통, 파과) 수확량 자동 환산 (kg)
- 주야간 온·습도, 일사량 및 **현장 사진(병충해 등) 첨부 및 메모**

### 4. 📊 영농 통계 & 분석 차트
- 최근 7일 / 14일 / 30일 데이터 인사이트
- EC / pH 추이 라인 차트, 일일 배액률 변화 그래프, 일자별 수확량 바 차트
- 핵심 KPI 요약 (총 수확량, 평균 배액률, 루틴 달성률)

### 5. ⚙️ 온실 설정 & 데이터 백업/내보내기
- 농장 이름 및 온실 베드 수(4~100개) 자유 변경
- **엑셀(CSV) 다운로드**: 일일 영농일지 전체를 엑셀에서 바로 열 수 있는 파일로 출력
- **전체 백업 (JSON)** 다운로드 및 파일 불러오기 복원 지원
- 100% 로컬 브라우저 저장(LocalStorage)으로 **인터넷이 불안정한 온실 내부에서도 완벽 동작**

---

## 🚀 사용 방법

### PC / 노트북에서 실행하기
- `index.html` 파일을 더블 클릭하여 크롬(Chrome)이나 엣지(Edge) 브라우저에서 바로 열 수 있습니다.

### 스마트폰(모바일)에서 앱처럼 사용하기
1. 스마트폰 브라우저에서 `index.html`을 실행합니다.
2. 브라우저 메뉴(또는 공유 버튼)에서 **"홈 화면에 추가"**를 누릅니다.
3. 스마트폰 바탕화면에 🍅 **토마토팜** 아이콘이 생성되며, 일반 스마트폰 앱처럼 전체화면으로 즉시 실행됩니다.

---

## 📂 파일 구성
- `index.html` : 모바일 최적화 고시인성 UI 및 대시보드
- `app.js` : 데이터 연산, 베드 매트릭스, 차트 시각화 및 로컬 스토리지 엔진
- `styles.css` : 온실 현장용 스타일 및 터치 인터랙션
- `manifest.json` & `sw.js` : 스마트폰 설치형 PWA 지원
